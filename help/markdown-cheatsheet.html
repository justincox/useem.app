Markdown cheatsheet

Every syntax em understands, Ghost cards included

Markdown is the greatest writing system ever devised, and em's customized version enhances it to support Ghost.

The fastest way to insert any Markdown code is by typing / at the start of a line in Edit mode and pick from the menu. em contains every option and only shows you the ones available wherever you are.

Ghost Cards

Some Ghost cards, like Pull Quote and Tables, are supported using existing Markdown formatting. Unique Ghost cards use a fenced block in the editor, meaning it starts with :::ghost-card plus the card type, some field: value lines, and a closing :::.

You don't need to memorize any of this — the / menu inserts a ready-to-edit template for every card (and you can also just start typing ::: to open a Ghost menu).

Callout

Markdown

:::ghost-card callout
emoji: 💡
color: #007AFF
Callout text.
:::


:::ghost-card callout
emoji: ⚠️
color: #FF0010
Callout text.
:::

Renders as

💡Callout text.


⚠️Callout text.

Images

Markdown

:::ghost-card image
source: https://example.com/image.jpg
caption: Optional caption
width: normal
:::

Renders as

width can be normal, wide, or full. Note: regardless of the width choice, em shows all images the same way.
