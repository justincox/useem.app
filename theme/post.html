Every Ghost Card, Rendered Properly

Everything em can publish to Ghost, styled the way it was meant to look — written in em, rendered by Paper and Ink.

Paper and Ink
September 5, 2026 • 4 min read

em's customized Markdown supports links, italics, bold, strikethrough, highlights, and every Koenig card Ghost knows how to render. This post walks through the ones that matter most and shows exactly how Paper and Ink styles each one — in whichever theme you're reading this in right now.

Callouts

Callouts get your point across, with or without an emoji.

💡
Blue works well for tips and asides.
Green reads as a quiet confirmation — no emoji needed.
⚠️
Red makes a warning look like one.

Code Blocks

Self-hosted syntax highlighting (no CDN), a language label, and long lines wrap with a hanging indent instead of forcing horizontal scroll.

function formatPost(markdown) {
  const rendered = em.render(markdown, { target: "ghost-lexical" });
  // Every card type below started as plain Markdown in em.
  return ghost.posts.publish(rendered, { status: "published" });
}
def word_count(path):
    with open(path) as f:
        text = f.read()
    return len(text.split())
